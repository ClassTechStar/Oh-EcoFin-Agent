## 摘要
- 一句话定位：教学演示用 A 股投研智能体，验证「工具调用 + 多空辩论 + 决策记忆」三机制。
- 核心数字占位：消融 C 组幻觉率对照 / D 组辩论增益 / walk-forward 衰减率 / 全周期成本 <¥100。

## 1 引言
- 问题：普通投资者缺投研能力；LLM 直接报数 = 幻觉重灾区。
- 方案：国产模型 + 国产数据 + 三机制课程级复现。
- 范围纪律（1.6 节逐条）：不做实时 tick / 分钟级回测 / 美港股 / 自动交易 / 用户系统 / 云数据库 / 多租户 / Docker 集群 / 模型微调。
